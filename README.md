# ร้านยาถุงเงิน — ระบบขายหน้าร้าน (POS)

เว็บแอปสำหรับขายสินค้าหน้าร้าน ทำงานฝั่งไคลเอนต์ล้วน (ไม่ต้องมีเซิร์ฟเวอร์/ฐานข้อมูล) เหมาะสำหรับ deploy ผ่าน **GitHub Pages** ใช้งานได้ฟรี

## ความสามารถ

**ขายสินค้า**
- **ค้นหาสินค้า** จากชื่อ รหัสสินค้า หรือเลขบาร์โค้ด (ข้อมูลสินค้า 7,308 รายการ จากไฟล์ Excel ที่ให้มา)
- **ยิงบาร์โค้ด**: ช่องค้นหารองรับเครื่องยิงบาร์โค้ดโดยตรง (ยิงแล้วสินค้าจะถูกเพิ่มลงตะกร้าอัตโนมัติ)
- **แยกบิล**: เปิดหลายบิลพร้อมกันได้ (ปุ่ม "+ แยกบิล") สลับไปมาระหว่างบิลได้ทันที แต่ละบิลมีตะกร้าของตัวเอง
- ปรับจำนวน/ลบสินค้าในบิล, ล้างบิล, คำนวณยอดรวมอัตโนมัติ
- **ชำระเงิน**: สรุปเป็นใบเสร็จ พิมพ์ได้ (Ctrl+P / ปุ่มพิมพ์ใบเสร็จ) — เมื่อกดปิด/พิมพ์ใบเสร็จ ระบบจะบันทึกบิลนั้นลงประวัติการขายอัตโนมัติ
- บิลที่เปิดค้างไว้จะถูกจำไว้ในเบราว์เซอร์ (localStorage) แม้ปิดหน้าเว็บแล้วเปิดใหม่

**แดชบอร์ด / ประวัติการขาย** (แท็บ "แดชบอร์ด" มุมบนของหน้าเว็บ)
- เลือกช่วงเวลาดูยอดขาย: วันนี้ / 7 วันล่าสุด / 30 วันล่าสุด / เดือนนี้ / ทั้งหมด
- การ์ดสรุป: ยอดขายรวม, จำนวนบิลที่ปิดแล้ว, จำนวนชิ้นที่ขาย, ยอดเฉลี่ยต่อบิล
- กราฟแท่งแสดงยอดขายรายวันตามช่วงที่เลือก
- ตารางย่อย 3 แบบ สลับดูได้: **รายบิล** (คลิกแต่ละบิลเพื่อดูใบเสร็จย้อนหลัง), **รายวัน**, **รายเดือน**

**พิมพ์ฉลากยา** — กดไอคอนฉลาก (🏷) ข้างสินค้าแต่ละแถวในบิล
- ชื่อยา ดึงมาจากชื่อสินค้าอัตโนมัติ แก้ไขได้
- เลือกวิธีใช้ (รับประทาน/ทา/หยอด/พ่น/อมใต้ลิ้น/เหน็บ-สอด), ปริมาณต่อครั้ง + หน่วย (เม็ด/ซีซี/ช้อนชา/ซอง/หยด ฯลฯ หรือระบุเอง)
- เลือกมื้ออาหาร (ก่อนอาหาร 30 นาที / ก่อนอาหาร / หลังอาหารทันที / หลังอาหาร / พร้อมอาหาร / ไม่ระบุ)
- เลือกความถี่ (วันละ 1-4 ครั้ง / ทุก...ชั่วโมง / เมื่อมีอาการ) และเวลาที่ใช้ (เช้า/เที่ยง/เย็น/ก่อนนอน เลือกได้หลายช่วง)
- กรอกข้อบ่งใช้/สรรพคุณ และชื่อผู้ป่วย (ไม่บังคับ)
- มีตัวอย่างฉลากแบบเรียลไทม์ ระบุจำนวนป้ายที่ต้องการพิมพ์ได้ (เผื่อกรณีมีหลายขวด/แผง) แล้วพิมพ์ออกมาเป็นฉลากขนาด 9 ซม. ต่อดวง

> ประวัติการขายเก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้นๆ (ไม่ได้ส่งขึ้นเซิร์ฟเวอร์กลาง) — ดูหัวข้อ "ข้อจำกัดที่ควรทราบ" ด้านล่าง

**สแกนบาร์โค้ดด้วยกล้องมือถือ** — ปุ่ม "สแกนด้วยกล้อง" ข้างช่องค้นหาด้านบน
- เปิดกล้อง (กล้องหลังของมือถือโดยอัตโนมัติ) ให้เล็งไปที่บาร์โค้ดสินค้า เมื่ออ่านเจอจะเพิ่มลงบิลให้เองทันที เหมือนยิงด้วยเครื่องสแกนจริง
- ใช้ร่วมกับเครื่องสแกนบาร์โค้ดแบบ USB/Bluetooth ที่มีอยู่แล้วได้ตามปกติ (เป็นอีกทางเลือกหนึ่ง ไม่ได้แทนที่)
- **ต้องเปิดผ่าน HTTPS เท่านั้น** (เบราว์เซอร์บล็อกการใช้กล้องบนหน้าที่ไม่ปลอดภัย) — ถ้า deploy ผ่าน GitHub Pages ตามขั้นตอนด้านล่าง จะได้ HTTPS ให้อัตโนมัติอยู่แล้ว ไม่ต้องตั้งค่าเพิ่ม
- ครั้งแรกที่ใช้ เบราว์เซอร์จะขออนุญาตใช้กล้อง กดอนุญาตได้เลย และต้องมีอินเทอร์เน็ตตอนใช้ครั้งแรก (เพื่อโหลดระบบอ่านบาร์โค้ด) หลังจากนั้นเบราว์เซอร์จะจำไว้ให้

## โครงสร้างไฟล์

```
pos-app/
├── index.html      หน้าเว็บหลัก (มุมบนสลับได้ระหว่าง "ขายสินค้า" และ "แดชบอร์ด")
├── style.css       ดีไซน์/ธีม (โทนเขียว-ทอง ตามโลโก้ถุงเงิน)
├── app.js          โค้ดตรรกะทั้งหมด (ค้นหา, ตะกร้า, แยกบิล, แดชบอร์ด, ประวัติการขาย)
├── products.json   ข้อมูลสินค้า (แปลงจากไฟล์ Excel ที่อัปโหลดมา)
├── assets/logo.png โลโก้มาสคอตถุงเงิน
└── README.md       ไฟล์นี้
```

## วิธีอัปเดตข้อมูลสินค้าในอนาคต

ไฟล์ `products.json` เก็บข้อมูลในรูปแบบนี้:

```json
{
  "name": "ชื่อสินค้า",
  "code": "รหัสสินค้า",
  "unit": "ชื่อหน่วย",
  "cost": 50.1,
  "price": 65.0,
  "barcodes": ["8858981102051"]
}
```

หากมีไฟล์ Excel หัวตารางเดิม (`รายการสินค้า, รหัสสินค้า, ชื่อหน่วย, ราคาทุน, ราคาขาย, เลขบาร์โค้ด 1-3`) สามารถให้ Claude แปลงเป็น `products.json` ใหม่แล้วแทนที่ไฟล์เดิมได้เลย

## วิธี deploy ขึ้น GitHub Pages (ฟรี)

1. สร้างบัญชี/ล็อกอิน [GitHub](https://github.com) แล้วสร้าง repository ใหม่ (เช่นชื่อ `tungngern-pos`) — เลือก Public

2. เปิด terminal ในโฟลเดอร์ `pos-app` นี้ แล้วรันคำสั่ง (แก้ `USERNAME` และ `tungngern-pos` ให้ตรงกับของจริง):

   ```bash
   git init
   git add .
   git commit -m "Initial Tungngern POS app"
   git branch -M main
   git remote add origin https://github.com/USERNAME/tungngern-pos.git
   git push -u origin main
   ```

3. ไปที่หน้า repository บน GitHub → **Settings** → **Pages** (เมนูซ้าย)

4. หัวข้อ "Build and deployment" → **Source** เลือก **Deploy from a branch**
   - Branch: เลือก `main` และโฟลเดอร์ `/ (root)`
   - กด **Save**

5. รอประมาณ 1-2 นาที เว็บจะพร้อมใช้งานที่:

   ```
   https://USERNAME.github.io/tungngern-pos/
   ```

6. เปิดลิงก์นี้บนคอมพิวเตอร์/แท็บเล็ตที่ร้าน ต่อเครื่องยิงบาร์โค้ด (แบบ USB/Bluetooth คีย์บอร์ด) แล้วใช้งานได้ทันที

> **หมายเหตุ**: ห้ามเปิดไฟล์ `index.html` โดยตรงจาก Finder/File Explorer (double-click) เพราะเบราว์เซอร์จะบล็อกการโหลด `products.json` ด้วยเหตุผลด้านความปลอดภัย (CORS) ต้องเปิดผ่านเว็บ (GitHub Pages) หรือรันเซิร์ฟเวอร์ในเครื่องก่อน เช่น `python3 -m http.server` แล้วเข้า `http://localhost:8000`

## การอัปเดตแอปในอนาคต

แก้ไขไฟล์แล้วรัน:

```bash
git add .
git commit -m "อัปเดต..."
git push
```

GitHub Pages จะ deploy เวอร์ชันใหม่ให้อัตโนมัติภายในไม่กี่นาที

## ข้อจำกัดที่ควรทราบ

- แอปนี้ไม่มีระบบตัดสต๊อกสินค้าจริง และไม่บันทึกประวัติการขายลงฐานข้อมูลกลาง (เก็บเฉพาะบิลที่เปิดค้างไว้ในเบราว์เซอร์เครื่องนั้นๆ) เหมาะกับร้านเล็กที่ต้องการเครื่องคิดเงินหน้าร้านแบบเรียบง่าย
- หากต้องการเชื่อมสต๊อก/รายงานยอดขายแบบเรียลไทม์หลายเครื่อง จะต้องเพิ่มฐานข้อมูลกลาง (เช่น Firebase, Supabase) ซึ่งสามารถต่อยอดจากโค้ดนี้ได้
- ฟีเจอร์สแกนด้วยกล้องมือถือโหลดไลบรารีจากอินเทอร์เน็ต (CDN) ตอนใช้งานครั้งแรกเท่านั้น และต้องเปิดหน้าเว็บผ่าน HTTPS — ถ้าเปิดไฟล์ `index.html` ตรงๆ หรือเปิดผ่าน HTTP ธรรมดา ฟีเจอร์นี้จะใช้ไม่ได้ (ส่วนการยิงด้วยเครื่องสแกน USB/Bluetooth และค้นหาพิมพ์เองยังใช้งานได้ปกติแบบออฟไลน์)
